# 游戏介绍与玩法

## 这是什么游戏

《人生重开模拟器》是一款**文字模拟养成游戏**：你投胎成新的人，用随机抽到的天赋和有限
的属性点开局，然后看着这个人从出生到死亡的一年一年过完。人生中会遇到什么事件、能活多久，
都取决于你的初始属性、天赋和一点运气。

死掉不是结束 —— 点「立即重开」就能再来一世。**重开次数越多，抽到高稀有度天赋的概率越高**，
所以每一世都在为下一世积累运气。

## 先玩线上版

电脑和手机浏览器都能直接玩，无需安装、无需注册：

**https://skyzenglu.github.io/liferestart-skyzl/**

想离线玩的话，见上方「本仓库包含什么」里的 Windows 便携版下载方式。

## 三种模式

开局可以在三个模式里选：

| 模式 | 玩法 |
| --- | --- |
| **经典模式** | 随机抽 10 个天赋，从中选 3 个，再自由分配属性点 |
| **名人模式** | 前世是古代名人，重开到了现代；开局需要抽角色，且重开次数有限制 |
| **我的命运我做主！** | 列出**全部**天赋，最多可选 10 个，彩色天赋另有上限（见下） |

## 一局的完整流程

```
选模式 → 抽天赋 → 选天赋 → 分配属性点 → 一年一年过完人生 → 结算评价 → 解锁成就
```

**第一步：抽天赋**

每次抽 10 个候选。天赋分 5 档，用颜色区分，越稀有越强：

| 档次 | 基础概率 |
| --- | --- |
| 白色 | 889 / 1000 |
| 蓝色 | 100 / 1000 |
| 紫色 | 10 / 1000 |
| 金色（橙色） | 1 / 1000 |
| **彩色** | 0.1 / 1000 |

**重开次数会放大高档天赋的概率**：抽到紫色、金色、彩色的概率随重开次数最多可提升到
**6 倍**（白色不变）。

**第二步：选天赋**

经典模式下从 10 个里选 3 个。解锁「功能」后还可以**锁定 1 个天赋**，让它在以后每一世
都必定出现。

**第三步：分配属性点**

基础 **20 点**，分配给 4 项属性，**单项最多 10 点**（快乐不占用这 20 点，默认从 5 开始）：

| 属性 | 影响 |
| --- | --- |
| **颜值** | 影响恋爱、社交类事件 |
| **智力** | 影响学业、职业、修炼类事件；高智力更容易走修仙路线 |
| **体质** | 影响健康和寿命，体质太低容易早夭 |
| **家境** | 影响财富、生活质量类事件 |
| **快乐** | 独立的幸福感数值，部分结局与它有关 |

有些天赋会额外赠送属性点，例如彩色天赋【禄】直接 **+2000 点**。

**第四步：过完这一生**

游戏按「岁」推进，每一年随机触发事件，属性随之增减。寿命耗尽（或 100 岁上限）后人生结束，
系统给出总评——从「地狱」到「传说」等档位。

**第五步：重开**

人生结束后进入结算，解锁成就、累积重开次数，然后开始下一世。

## 26.9-2 更新内容

### 新增天赋

| 天赋 | 稀有度 | 描述 | 效果 |
| --- | --- | --- | --- |
| **【生生不息】** | 彩色 | 我看到了【生生不息】的激荡。 | 智力为**负数**时不会死亡，死亡会被复活 |
| **【智力残缺】** | 白色 | 你的智力恒定为-1 | 无论何时触发何等效果，智力**恒定为 -1** |

**【生生不息】** 复活时会播放提示：

> 【生生不息】的力量将你从死亡中拉回。

**【智力残缺】** 会彻底封死智力线：开局分配的智力点直接作废，所有加智力的事件与天赋
（包括修仙路线的 `INT>100` 等门槛）都无法生效。

> ⚠️ 两个天赋组合起来 = **绝对不死**（智力恒为 -1 → 每次死亡都复活，可活到 500 岁）。
> 这是两者分别实现后的自然结果，如果不想要这个组合可以反馈。

## 这一版新增了什么

本修改版在原作者基础上增加了彩色天赋档、自定义模式、修仙路线扩展、驭鬼者路线、
存档导入导出、Android 离线端和 Windows 便携版。详细清单见
[README-M3-APK.md](./README-M3-APK.md)。

几个值得试的：

- **【禄】**（彩色）：初始属性点 +2000、快乐 +100 —— 开局就能把属性拉满
- **【先天道体】**（彩色）：修炼和事件中提升的体质、智力**变为十倍**
- **【法则之子】**（彩色）：悟出大道、天道的概率**变为十倍**
- **【仙族弟子】**（彩色）：12 岁开始修炼，需搭配【神秘的小盒子】
- **【生生不息】**（彩色）：智力为负时死亡会复活
- **【智力残缺】**（白色）：智力恒定为 -1
- **【鬼眼】**（金色）：进入驭鬼者路线 —— ⚠️ **该路线当前存在已知 bug，仅供测试**

彩色天赋的可用数量随**已解锁成就数**增加：0-39 个成就每局可选 1 个，每多 40 个成就多 1 个，
最多 5 个。

## 上手建议

- **先随便玩几世**：天赋和属性都靠运气，前几局主要是熟悉事件类型和积累重开次数
- **前期优先体质和智力**：体质太低会早早死掉，智力影响后期路线的开启条件
- **重开次数是关键资源**：想抽到彩色天赋，最有效的办法就是多玩
- **别急着冲驭鬼者路线**：这条路线目前有已知 bug，等后续修复再认真玩
- **注意一些天赋是互斥的**：【鬼眼】与【仙族弟子】【神秘的小盒子】无法同时获得
